Understanding the Concept

  1. A binary search tree is built such that all numbers on the left are smaller, and all numbers on the right are larger.
  2. For this challenge, given a range, e.g., low = 7 and high = 10, we need to trim all numbers that are out of this boundary. This means we only retain numbers between 7 and 10, removing anything smaller than 7 or larger than 10.
  3. The smart move is passing the left or right branch recursively into the function.
  4. If the root is smaller than the lower bound, then the answer lies somewhere in the right branch, so we pass the right branch as the new root: 
    5. if root.val < low: 
    return self.trimBST(root.right, low, high)
  5. This "trims" the left branch by just moving the root pointer. All the nodes in the left branch still exists in memory. Just that the root pointer now points at the right branch.
  6. Similarly, if the root is larger than the upper bound, move the root pointer to the left node: 
    7. if root.val > high:
    return self.trimBST(root.left, low, high)
  7. Finally, when the root is within the range, it proceeds to trim left and right branches recursively and return the root: 
    8. root.left = self.trimBST(root.left, low, high)
root.right = self.trimBST(root.right, low, high)
return root
  8. The full code:
    9. class Solution:
    def trimBST(self, root: TreeNode, low: int, high: int) -> TreeNode:
        if not root:
            return None
        if root.val < low: 
            return self.trimBST(root.right, low, high) 
        if root.val> high:
            return self.trimBST(root.left, low, high)
        root.left = self.trimBST(root.left, low, high)
        root.right = self.trimBST(root.right, low, high)
        return root
